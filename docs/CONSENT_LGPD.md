# Consentimento LGPD

## Finalidade

O MobTrainer coleta dados pessoais para fins de:

- cadastro e autenticação do usuário
- acompanhamento de metas físicas e nutricionais
- recomendação de treinos e planos personalizados
- comunicação sobre serviços e suporte ao usuário

## Dados tratados

Podemos processar dados como:

- nome e e-mail
- idade, sexo e informações de saúde relevantes
- metas de treino e nutrição
- histórico de atividades e preferências
- dados de uso do aplicativo para melhoria da experiência

## Base legal

A coleta e o tratamento serão realizados com base no consentimento do titular, conforme a Lei Geral de Proteção de Dados (LGPD).

## Direitos do titular

O usuário pode, a qualquer momento, solicitar:

- confirmação do tratamento
- acesso aos dados pessoais
- correção de dados
- eliminação dos dados
- portabilidade
- revogação do consentimento
